# LEAP-One turntable

The viewer streams path-traced frames of `public/media/models/leap-one.glb` (the lossless Onshape export with the new bottom support). `scripts/render-leap-one-turntable.py` builds the scene in Blender and renders it with Cycles on the GPU (OptiX ray tracing and the OptiX denoiser); `scripts/render-leap-one-turntable.mjs` is the launcher that finds Blender, runs the script and then calls `scripts/encode-leap-one-turntable.mjs`, which composites the PNG frames onto the page colour and writes the WebP sequence (2400×1800 desktop, 1200×1200 centre-cropped mobile).

The scene is lit by the page itself: the environment is built from the section's near-black ground, its warm glow on the upper left, its cool glow on the lower right and its faint grid, and a small studio rig follows the same warm-left / cool-right split. The floor is a dark, slightly glossy plane that dissolves into the page colour beyond the rover; the frames are rendered with a transparent film so the encoder composites that colour exactly. A fixed orthographic camera keeps the world-to-pixel scale constant at every angle; do not reintroduce perspective or per-frame auto-fitting.

The CAD assembly leaves the suspension slightly articulated, so the script fits a plane through the six tyre contact points, tilts the body onto it and places the floor at the median contact height; otherwise the wheels hover or sink. Geometry and colours stay with the CAD; pale neutral parts receive a brushed metal finish, the orange extrusions a slight sheen.

`npm run render:leap-one-turntable -- --preview` renders six angles at reduced samples into the operating system's temporary directory and never touches the sequence displayed on the site. Pass `--model=<path>` to try a different export, `--samples=<n>` or `--scale=0.5` for quicker looks.

For a new complete sequence, run `npm run render:leap-one-turntable -- --version=v7` (choose an unused version). It renders 720 half-degree frames; on the RTX 500 laptop GPU this takes several hours, so a run can be split (`--start`/`--end`) or continued after an interruption with `--resume`. `--encode-only` re-encodes frames that are already rendered. Blender 4.x must be installed (the launcher looks in Program Files, or set `BLENDER` to the executable).

Inspect the full orbit and verify all 720 files in both directories before changing the version in `RoverTurntable.tsx`. Never publish or point the viewer at an incomplete batch. A new URL also prevents browsers from mixing cached older renders with new ones.

Playback targets 60 fps. Compressed frames stay resident in a wide window; only a short run ahead of the current angle is decoded, and older bitmaps are closed. The rover turns slowly on its own, a drag or flick takes over immediately (fast drags show the nearest decoded frame so motion never waits on the network), and the idle turn eases back in a moment after the last interaction, from wherever the rover was left. Playback stops when offscreen or when the browser tab is hidden. Reduced-motion visitors get a still view that they can still drag, without coasting. The stage is keyboard focusable: the arrow keys rotate the rover and Home returns to the opening view. There are no visible controls; the frame edges are masked so the rover stands directly on the page.
